## ⭐ Featured Projects

### 🚚 Logistics Orchestration Platform
**Event-Driven Shipping Management System**

A distributed backend platform that coordinates the shipping lifecycle—from inventory reservation and warehouse processing to carrier selection and shipment tracking. Built to explore reliable communication between independent services without tightly coupling their business logic.

**Tech Stack:** `Node.js` `TypeScript` `Express` `PostgreSQL` `Prisma` `Apache Kafka` `Docker Compose` `React` `Vite` `Material UI`

**Key Engineering Highlights**

- 🧩 **Microservices architecture:** Separate services for inventory, warehouse operations, carrier selection, shipment management, and event storage.
- 🔄 **Event-driven workflows:** Apache Kafka coordinates asynchronous communication between services.
- 🛡️ **Transactional outbox pattern:** Persists business updates and outgoing events together to reduce database/message-broker consistency problems.
- ♻️ **Idempotent consumers:** Handles duplicate event delivery safely using event identifiers and database constraints.
- 🗄️ **Database-per-service approach:** Isolates service data in separate PostgreSQL databases.
- 📦 **Shipment lifecycle management:** Coordinates inventory reservation, warehouse processing, deterministic carrier selection, and shipment status transitions.
- ⚙️ **Dockerized infrastructure:** Runs the services and supporting infrastructure using Docker Compose.
- 📊 **Operations dashboard:** Provides visibility into shipments, operational metrics, and the event timeline.

**What I explored:** Distributed workflows, asynchronous processing, event contracts, service boundaries, consistency, and failure handling.
